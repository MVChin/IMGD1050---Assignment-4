# IMGD1050---Assignment-4

I used US annual rainfall data obtained from NOAA.  The data contains 120 years worth of information including the average annual rainfall and whether it is greater than on less than expected.  Unfortunately, the data does not have any baseline information.  The visual appears as a spiral with the earliest data in the centre and shows relative amounts based on the size of the circle as well as the if the anomaly is postive or negative; green for positive, red for negative.  
The plan for the visual is for the user to see any trends in rainfall over time as well as if it is exceeding oe less than expected conditions for than year.
